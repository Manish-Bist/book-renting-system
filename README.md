# Book Zone — Online Book Rental System

Book Zone is a web application for browsing, searching, and renting books online. It features a full customer frontend along with an admin interface for managing inventory, categories, and customer orders.

I built this project using PHP and MySQL to learn full-stack web development, handle dynamic database queries, and manage user sessions and authentication.

## Features

- **User Accounts:** Registration, login, and session management.
- **Book Browsing:** Filter titles by genre (Adventure, Thriller, Romance, Comedy) or by rental type (New/Old books).
- **Cart & Rental Flow:** Add books to cart and process rental selections.
- **Feedback Form:** Contact form for user inquiries and suggestions.
- **Admin Panel:** Management interface to add/update books, monitor stock, and review customer rentals.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Environment:** XAMPP / WAMP
